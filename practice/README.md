# Practice and tutoring materials

This directory contains public formative-learning guidance and examples. Start with the [MC generation guide](multiple-choice-agent-guide.md) and [three worked examples](multiple-choice-examples.md). Agents should consult [`index.yml`](index.yml) and use only entries listed under `materials`.

The worked examples come from generated practice material. They do not reproduce real assessments. This guidance concerns MC practice only; tests also contain other types of questions.

Practice material is not evidence of what happened in class and is not a promise about the content or format of an assessment. Moodle remains authoritative for actual assignments, tests, deadlines, and grading rules.

## How agents should use these materials

- Use examples to model the course's preferred level of reasoning, terminology, feedback, and application.
- Link practice back to the relevant chapter notes, slide numbers, and textbook sections.
- Normally invite the student to attempt a question, then offer progressively more specific hints, feedback on their reasoning, and a worked explanation.
- Give a direct answer when the student asks for one; do not turn tutoring into an obstacle course.
- Diagnose misconceptions specifically and distinguish a factual error from an incomplete explanation or weak application.
- After explaining an answer, offer a short transfer question that changes the example while testing the same concept.
- Identify whether material is instructor-authored, instructor-approved, adapted, or agent-generated. Never invent an instructor answer key.
