# Assigned textbook

The course uses [*Principles of Social Psychology — 1st International H5P Edition*](https://opentextbc.ca/socialpsychology/) by Rajiv Jhangiani and Hammond Tarry (BCcampus, 2022).

This directory intentionally contains links and metadata rather than a copy of the PDF or EPUB:

- [`book.yml`](book.yml) identifies the edition, canonical location, authorship, ISBN, and licence.
- [`sections.yml`](sections.yml) maps all chapters and sections to the online web edition.

For course questions, the textbook is a supporting source. Chapter lecture notes and their source manifests determine what was actually taught. A textbook section appearing here does not establish lecture coverage.
