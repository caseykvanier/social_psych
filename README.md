# Fundamentals of Social Psychology

Agent-ready, accessible course materials for **Fundamentals of Social Psychology** at Vanier College, Autumn 2026.

This repository pairs each classroom slide deck with detailed, slide-by-slide lecture notes. Its main purpose is to give students' study agents a clear, structured, source-grounded representation of the course. The same files remain readable for students who want to use them directly.

> These notes are a course companion, not a substitute for attending class, completing assigned work, or checking Moodle for current instructions and deadlines.

## Agent quick start

Point an agent to this repository and ask it to read, in order:

1. [`AGENTS.md`](AGENTS.md) for evidence and answer rules.
2. [`course.yml`](course.yml) for the machine-readable course and chapter map.
3. The relevant chapter's `notes.md` and `sources.yml`.
4. [`practice/index.yml`](practice/index.yml) for available formative-learning materials.
5. [`textbook/sections.yml`](textbook/sections.yml) when textbook support is useful.

[`llms.txt`](llms.txt) provides a compact plain-text entry point for tools that recognize that convention. For questions about what was taught, lecture notes outrank slides and the textbook; the textbook provides background but never establishes lecture coverage.

## Practice and tutoring support

Students can give their own study agents the [multiple-choice generation guide](practice/multiple-choice-agent-guide.md). It explains source grounding, credible distractors, a mix of reasoning demands, and feedback that helps students learn from mistakes. [Three worked examples](practice/multiple-choice-examples.md), adapted from generated practice questions, illustrate the approach.

These are public formative materials, not actual or predicted test questions. The course's tests also use other question types; this guide focuses only on MC practice. The suggested difficulty mix is a practice-design choice, not a test blueprint. Moodle remains authoritative for assessment instructions.

The [agent-readable registry](practice/index.yml) lists active materials.

## How to use these materials

- Open the slide deck and notes together. Every PDF page has one matching numbered section in `notes.md`.
- Use the “What the slide shows” section as a text alternative for important visuals.
- Use “Detailed notes” for the instructor’s explanations, examples, distinctions, and cautions.
- Consult `sources.yml` inside each chapter for lecture dates, review status, and coverage boundaries.
- Treat Moodle as the authoritative source for assessments, deadlines, announcements, and any later corrections.

## Textbook

The assigned open textbook is [*Principles of Social Psychology — 1st International H5P Edition*](https://opentextbc.ca/socialpsychology/) by Rajiv Jhangiani and Hammond Tarry. The repository includes an [agent-readable book record](textbook/book.yml) and [section-level link catalog](textbook/sections.yml), not a duplicate ebook. This keeps the repository small and sends readers to the canonical accessible web edition.

The textbook is licensed CC BY-NC-SA 4.0 except where otherwise noted; some adapted material has different Creative Commons terms. See [`textbook/README.md`](textbook/README.md) for attribution and use details.

## For study agents

Repository-specific instructions are in [AGENTS.md](AGENTS.md), and the complete corpus map is in [course.yml](course.yml). Agents should cite repository-relative files, preserve uncertainty, distinguish course evidence from textbook background, and never invent lecture coverage for material marked incomplete.
